Atlas

Atlas is a web application that lets users explore countries around the world.

Features

- View countries
- Search for a country
- View country details
- Dark mode
- Responsive design
- Loading and error states

Built With

- React
- TypeScript
- Vite
- CSS
- REST Countries API

How to Run

Install the dependencies:

npm install

Start the app:

npm run dev

To create a production build:

npm run build
