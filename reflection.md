Atlas Reflection

Building Atlas helped me understand how to build a dynamic web application with React and TypeScript.
One of the main things I learned was how to work with an API and display the data dynamically. I also learned how to handle loading, error, and empty states instead of only displaying data when everything works correctly.
I had some challenges while working on the project, especially with the API connection and routing. I had to troubleshoot the API request and make sure the country details page worked correctly when a country was selected.
I also improved my understanding of responsive design, accessibility, reusable components, and performance. Adding keyboard focus styles, proper labels, lazy loading for images, and testing the production build with Lighthouse helped me understand that a good application is not only about making it work but also making it accessible and efficient.
Overall, Atlas gave me more confidence working with React, TypeScript, APIs, and Git/GitHub. There are still areas I can improve, especially image optimization and caching, but I am happy with the final result and what I learned from building the project.
